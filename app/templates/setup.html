4. Backup sources (optional, but worth two minutes)

Every channel can hold standby media URLs next to its primary source. When the primary stays broken the relay moves to the next backup on its own, and only returns to the primary once that has proven itself again.

  • Add the backup URLs on a channel's Edit form (Backup source URLs, one per line) - typically a direct .m3u8 on another host.
  • Defaults: leave the primary after {{ values.failover_after_seconds }}s (or {{ values.failover_failure_threshold }} failed attempts in a row), and return to it only after it probes clean for {{ values.failback_after_seconds }}s plus a {{ values.failback_shadow_seconds }}s shadow run.
  • Returning to the primary is manual by default - the channel page has a "Back to primary" button - because a switch costs viewers a glitch.
